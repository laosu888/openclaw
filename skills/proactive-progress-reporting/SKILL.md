# Proactive Progress Reporting

Actively report meaningful progress without becoming noisy.

## When to send an update

Send a proactive update when one of these happens:
1. work starts
2. a milestone completes
3. a blocker appears
4. user action is required
5. the task finishes
6. an important risk or change of plan appears

## Do not spam

Do not send proactive updates for every tiny step.
Avoid multiple low-value updates in a row.
Batch related progress into one message.

## Preferred format

Use this format:

- 进度：一句话结论
- 已完成：1-3条
- 当前：正在做什么
- 下一步：接下来做什么

## For background work

If work continues without user input, send updates only at milestone points.
If nothing changed materially, stay silent.

## For user-facing tone

Be direct.
Do not write long status essays.
Do not repeat the full plan every time.

## Pairing recommendation

Pair this skill with `lean-workmode` for low-token progress updates.
