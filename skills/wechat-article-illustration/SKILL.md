# wechat-article-illustration

先做**配图策略判断**，再做图片执行。默认规则：**真实图优先，AI 图兜底**。

## 核心原则

1. **先找真实图，不先生图**。
2. **封面和正文首图不能重复**。
3. **正文图避免强重复**，优先横版，少用低质量截图。
4. **AI 图只做补位**：真实图不足、表达力不够、或封面需要更强视觉时再用。
5. **图片服务文章，不服务炫技**。

## 先判断文章类型

先把文章归到最接近的一类：

- **项目解析 / GitHub 项目**：真实图占主力。优先 README、docs、官网、demo、benchmark 图。
- **新闻评论 / 热点解读**：真实图优先。优先官方图、人物图、发布会图、媒体原图。AI 图可补封面。
- **教程文 / 配置文**：教程图、官方文档图、界面图优先。正文尽量不用 AI 图。
- **概念观点文 / 趋势文**：真实图 + AI 图混合可接受，但正文至少保留 2-3 张真实图。
- **产品介绍 / 公司分析**：优先官网主视觉、产品页面、功能图、官方博客图。

如果拿不准，按“**读者最需要看到真实信息还是抽象氛围**”来判断。

## 真实图搜索优先级

按这个顺序找：

1. **官方图**
   - 官网 / 官方博客 / 新闻稿 / GitHub README / 仓库 assets / docs
2. **产品真实图**
   - demo 图 / 界面图 / 发布会图 / 实拍图 / benchmark 图
3. **媒体原图**
   - Reuters / CNBC / TechCrunch / 36氪 / 机器之心 / 量子位 / 新智元 等

不要默认拿二次转载截图。优先找原始图源或 og:image。

## 何时触发 AI 图

只有满足下面至少一条，才考虑 AI 图：

- 真实图数量不够：封面 1 张 + 正文 3-5 张凑不齐
- 真实图表达不了文章核心：例如“记忆系统”“未来协作”“抽象趋势”
- 封面需要统一视觉或更强传播感，但正文真实图已经足够

### 不同文章类型的 AI 图上限

- **项目解析 / GitHub 项目**：AI 图最多 0-1 张，优先只补封面
- **新闻评论 / 热点解读**：AI 图最多 1-2 张，优先补封面
- **教程文 / 配置文**：正文默认不用 AI 图；最多允许封面 1 张
- **概念观点文 / 趋势文**：AI 图可做 1-2 张补位，但别整篇全 AI

## 执行时必须检查四件事

1. **数量**：封面 1 张，正文 3-5 张
2. **质量**：清晰、横版优先、无明显水印、不是糊截图
3. **匹配**：图要能表达文章核心，不只是“沾边”
4. **重复感**：封面 ≠ 正文首图；正文图之间别一个模子

## 输出格式

执行本 skill 时，先给出一个简短策略结论，再落地找图/生图：

- 文章类型：xxx
- 封面策略：真实图 / AI 图
- 正文策略：真实图为主 / 真实图+AI补位
- 推荐图数：封面 1 + 正文 3-5
- 真实图优先来源：xxx
- 是否触发 AI 图：是 / 否
- 触发原因：真实图不足 / 表达力不足 / 封面补位

然后再实际执行。

## 调用其他技能的规则

- 需要搜文章/项目/官网素材时，用搜索/网页读取能力。
- 需要 AI 生图时，再调用已安装的生图技能（如你当前环境里可用的图像生成 skill）。
- 不要因为会生图，就跳过真实图搜索。
