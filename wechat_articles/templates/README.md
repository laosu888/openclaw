# 公众号模板库

## 模板说明

### 1. green-tech-deep.html
- 绿色科技深度风（轻量版）
- 适合：OpenClaw、AI 工具、GitHub 热点、产品分析、趋势长文

### 2. ai-hot-commentary.html
- AI 热点快评风（轻量版）
- 适合：AI 公司动态、模型更新、行业快评、热点评论

### 3. tutorial-clean.html
- 极简教程风（轻量版）
- 适合：配置指南、操作教程、步骤说明、实操文章

### 4. green-tech-premium.html
- 绿色科技旗舰深度风（重内容版）
- 适合：产品拆解、AI 架构、GitHub 项目深度分析、方法论长文

### 5. ai-hot-commentary-pro.html
- AI 热点快评升级版
- 适合：AI 热点、行业判断、快评、态度文

### 6. tutorial-card-clean.html
- 卡片式教程清单风
- 适合：操作手册、配置步骤、Checklist、工具教程

### 7. alert-commentary-315.html
- 警示评论风
- 适合：315、风险、争议事件、打假、社会议题 + AI 结合

## 使用原则
- 深度分析 / 项目拆解：优先 `green-tech-premium.html`
- 普通深度文 / 趋势文：优先 `green-tech-deep.html`
- 热点评论 / AI快评：优先 `ai-hot-commentary-pro.html`
- 强警示 / 315 / 风险议题：优先 `alert-commentary-315.html`
- 配置指南 / 教程 / 清单：优先 `tutorial-card-clean.html`
- 简单教程或短教程：优先 `tutorial-clean.html`
