# 公众号模板库

## 模板说明

### 1. green-tech-deep.html
- 绿色科技深度风
- 适合：OpenClaw、AI 工具、GitHub 热点、产品分析、趋势长文

### 2. ai-hot-commentary.html
- AI 热点快评风
- 适合：AI 公司动态、模型更新、行业快评、热点评论

### 3. tutorial-clean.html
- 极简教程风
- 适合：配置指南、操作教程、步骤说明、实操文章

## 使用原则
- 深度分析 / 项目拆解：优先 `green-tech-deep.html`
- 热点评论 / AI快讯延展：优先 `ai-hot-commentary.html`
- 配置指南 / 教程 / 清单：优先 `tutorial-clean.html`

## 后续规则
以后写公众号时，优先先选题，再按题型自动匹配模板，不再每次临时拼排版。
